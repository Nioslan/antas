# Antas Finanzas

App nueva (paquete `com.antas.finanzas`), arranque estable.

- Datos solo en el teléfono
- Sin OTA / sin notificaciones nativas (por ahora)
- Pack: movimientos, fijos, metas, presupuestos, sobres, deudas, calendario, reto, hogar, reportes

Instalá el APK nuevo (no la app vieja). Podés importar un respaldo JSON desde Ajustes.
